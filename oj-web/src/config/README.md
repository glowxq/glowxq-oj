# 地图功能配置说明

## 高德地图API密钥配置

为了使用地图选择功能，您需要申请高德地图API密钥。

### 1. 申请API密钥

1. 访问高德开放平台：https://console.amap.com/dev/key/app
2. 注册并登录账号
3. 创建新应用
4. 添加Web端（JS API）密钥
5. 配置域名白名单（开发环境可以设置为 `localhost`）

### 2. 配置密钥

#### 方法一：环境变量（推荐）
在项目根目录创建 `.env.local` 文件，添加：

```bash
# 高德地图API密钥
VITE_AMAP_KEY=your_actual_api_key_here
```

#### 方法二：直接修改配置文件
编辑 `src/config/map.ts` 文件，将 `demo-key-for-development` 替换为您的实际API密钥：

```typescript
amap: {
  key: 'your_actual_api_key_here', // 替换为实际密钥
  // ...其他配置
}
```

### 3. 功能特性

- ✅ 地图点击选择位置
- ✅ 标记拖拽调整位置  
- ✅ 地址搜索功能
- ✅ 逆地理编码（坐标转地址）
- ✅ 浏览器定位
- ✅ 详细地址信息获取

### 4. 使用说明

地图选择器会自动：
- 更新经纬度坐标
- 填充详细地址信息
- 更新位置描述
- 如果有详细地址信息，会自动填充到对应字段

### 5. 注意事项

- 确保API密钥对应的应用已添加当前域名到白名单
- 开发环境建议使用 `localhost` 域名
- 生产环境需要配置实际的域名
- API密钥有调用量限制，请根据实际需求选择合适的套餐

### 6. 常见问题

**Q: 地图加载失败？**
A: 检查API密钥是否正确，域名是否在白名单中

**Q: 无法获取地址信息？**  
A: 确保API密钥包含地理编码服务权限

**Q: 搜索功能不可用？**
A: 确保API密钥包含搜索服务权限
