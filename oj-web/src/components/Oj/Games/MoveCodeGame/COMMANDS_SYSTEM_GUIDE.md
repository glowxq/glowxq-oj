### 数据字段说明
- **category**: 指令分类名称
- **icon**: 分类图标（emoji）
- **description**: 分类描述
- **commands**: 该分类下的指令列表
  - **name**: 指令名称
  - **description**: 指令描述
  - **syntax**: 语法格式
  - **example**: 示例代码
  - **level**: 难度级别（基础/中级/高级）
  - **color**: 显示颜色
  - **params**: 参数说明（可选）
  - **returns**: 返回值说明（可选）
  - **note**: 特殊说明（可选）

### 指令分类

#### 🎮 基础移动指令
- `moveRight()` - 向右移动一格
- `moveLeft()` - 向左移动一格
- `moveUp()` - 向上移动一格
- `moveDown()` - 向下移动一格

#### 🚀 高级移动指令
- `direction(方向)` - 设置英雄面向方向
- `fd(步数)` - 向前移动指定步数
- `rt()` - 向右转90度

#### 🔄 循环控制
- `for循环` - 重复执行指定次数的代码
- `while循环` - 在条件为真时重复执行代码

#### 🤔 条件判断
- `if-else` - 条件判断语句

#### 📍 位置检测
- `getHeroPosition()` - 获取英雄当前位置
- `hasObstacle(x, y)` - 检查指定位置是否有障碍物
- `hasTreasure(x, y)` - 检查指定位置是否有宝箱

#### 🔍 高级检测
- `thereObstacles()` - 获取周围障碍物的方向信息
- `isThereObstacles(方向)` - 检查指定方向是否有障碍物
- `reachBoundary()` - 获取到达的边界信息
- `isReachBoundary(方向)` - 检查指定方向是否到达边界

#### ⚔️ 战斗指令
- `attack()` - 使用当前武器攻击前方怪物
