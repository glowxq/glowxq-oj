## 🎮 新增关卡详情

### 关卡9：条件判断 - 路径选择 🔀
**设计理念**：引入条件判断概念，让学习者学会根据环境状态做出决策

**关卡特色**：
- Y形分叉路径设计
- 需要使用`hasObstacle(x, y)`函数检查障碍物
- 根据检查结果选择正确的路径

**学习目标**：
- 掌握if-else基本语法
- 理解条件判断的逻辑
- 学会使用辅助函数获取游戏状态

**核心代码模式**：
```javascript
// 到达分叉点
for(let i = 0; i < 5; i++) {
  moveRight()
}

// 条件判断选择路径
if (hasObstacle(7, 3)) {
  moveDown()  // 选择下方路径
  moveRight()
} else {
  moveUp()    // 选择上方路径
  moveRight()
}
```

## 🔧 新增辅助函数

### hasObstacle(x, y)
**功能**：检查指定坐标是否有障碍物
**实现**：
```typescript
const hasObstacle = (x: number, y: number): boolean => {
  return gameWorld.obstacles.some(obstacle => 
    obstacle.position.x === x && obstacle.position.y === y
  )
}
```

### hasTreasure(x, y)
**功能**：检查指定坐标是否有未收集的宝箱
**实现**：
```typescript
const hasTreasure = (x: number, y: number): boolean => {
  return gameWorld.treasures.some(treasure => 
    treasure.position.x === x && treasure.position.y === y && !treasure.collected
  )
}
```
