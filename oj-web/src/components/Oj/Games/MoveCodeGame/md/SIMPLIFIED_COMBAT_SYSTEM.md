# ⚔️ 简化战斗系统指南

## 📋 系统概述

根据您的要求，我已经简化了战斗系统，保留核心的武器和怪物机制，让系统更加简洁易懂。

## 🎮 游戏元素

### 👹 怪物系统
**两种类型**：
- **物理系怪物** 👹：红色显示，需要用剑攻击
- **魔法系怪物** 🔮：蓝色显示，需要用魔杖攻击

**特点**：
- 不同颜色区分类型
- 一击必杀机制
- 武器类型必须匹配才能击败

### ⚔️ 武器系统
**两种武器**：
- **剑** ⚔️：攻击前方一个格子的物理系怪物
- **魔杖** 🪄：向前方发射火焰攻击魔法系怪物

**特点**：
- 只能持有一个武器
- 拾取新武器会覆盖旧武器
- 武器类型决定能击败的怪物类型

### 🎯 界面显示
**武器框**：
- 位置：游戏界面上方
- 显示：当前装备的武器图标和名称
- 状态：未装备时显示"空"

## 🎮 新增指令

### attack() - 攻击指令
**功能**：使用当前装备的武器攻击前方怪物

**攻击规则**：
- **剑 ⚔️** → **物理系怪物 👹**：✅ 一击击败
- **剑 ⚔️** → **魔法系怪物 🔮**：❌ 无效攻击
- **魔杖 🪄** → **魔法系怪物 🔮**：✅ 一击击败  
- **魔杖 🪄** → **物理系怪物 👹**：❌ 无效攻击

**使用示例**：
```javascript
// 装备武器后攻击
direction(2)  // 面向怪物方向
attack()      // 攻击前方怪物
```

## 🔧 技术实现

### 武器匹配逻辑
```typescript
const attack = (): void => {
  if (!heroWeapon.value) {
    ElMessage.warning('没有装备武器，无法攻击')
    return
  }
  
  const targetMonster = findTargetMonster()
  
  if (targetMonster) {
    // 检查武器类型是否匹配怪物类型
    const canKill = (weapon.weaponType === 'sword' && targetMonster.monsterType === 'physical') ||
                   (weapon.weaponType === 'staff' && targetMonster.monsterType === 'magical')
    
    if (canKill) {
      targetMonster.alive = false
      targetMonster.symbol = '💀'
      ElMessage.success(`击败了怪物！`)
    } else {
      ElMessage.warning(`武器对此怪物无效！`)
    }
  }
}
```

### 武器拾取机制
```typescript
const checkWeaponCollection = (): void => {
  const heroPos = gameWorld.hero.position
  
  gameWorld.weapons.forEach(weapon => {
    if (!weapon.collected && weapon.position.x === heroPos.x && weapon.position.y === heroPos.y) {
      weapon.collected = true
      
      // 替换当前武器
      if (heroWeapon.value) {
        ElMessage.info(`替换了武器`)
      } else {
        ElMessage.success(`装备了武器`)
      }
      
      heroWeapon.value = weapon
    }
  })
}
```
