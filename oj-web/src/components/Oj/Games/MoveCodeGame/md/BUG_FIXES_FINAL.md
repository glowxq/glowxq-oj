## 🐛 问题1：fd()函数调用错误

### 问题描述
```
(in promise) ReferenceError: moveRight is not defined at fd (MoveCodeGame.vue:467:7)
```

### 问题原因
fd()函数试图直接调用moveRight()等函数，但这些函数是在createGameAPI中动态创建的，在fd()函数的作用域中不可访问。

### 解决方案
将fd()函数改为直接调用底层的moveHero()函数：

**修复前**：
```typescript
const fd = async (): Promise<void> => {
  if (!gameWorld.hero) return
  
  const direction = gameWorld.hero.direction || 'right'
  
  switch (direction) {
    case 'up':
      await moveUp()      // ❌ moveUp未定义
      break
    case 'right':
      await moveRight()   // ❌ moveRight未定义
      break
    // ...
  }
}
```

**修复后**：
```typescript
const fd = async (): Promise<void> => {
  if (!gameWorld.hero) return
  
  const direction = gameWorld.hero.direction || 'right'
  
  switch (direction) {
    case 'up':
      await moveHero(0, -1)   // ✅ 直接调用moveHero
      break
    case 'right':
      await moveHero(1, 0)    // ✅ 直接调用moveHero
      break
    case 'down':
      await moveHero(0, 1)    // ✅ 直接调用moveHero
      break
    case 'left':
      await moveHero(-1, 0)   // ✅ 直接调用moveHero
      break
  }
}
```

### 技术说明
- `moveHero(dx, dy)`是底层的移动函数，接受相对位移参数
- `dx, dy`分别表示X轴和Y轴的位移量
- 这种方式避免了作用域问题，确保函数调用的可靠性

## 🔧 技术实现细节

### moveHero函数的参数说明
```typescript
// moveHero(dx, dy) 参数对应关系
moveHero(0, -1)   // 向上移动：Y坐标减1
moveHero(1, 0)    // 向右移动：X坐标加1
moveHero(0, 1)    // 向下移动：Y坐标加1
moveHero(-1, 0)   // 向左移动：X坐标减1
```

### 方向与坐标系统
```

      ↑
      |

      |
    (0,1)
      ↓
```
