## 🎯 功能1：关卡数据抽离

### 文件结构
```
src/components/Oj/Games/MoveCodeGame/
├── MoveCodeGame.vue          # 主游戏组件
├── MapEditor.vue             # 地图编辑器组件
├── levels.json               # 关卡数据文件
└── LEVEL_SYSTEM_GUIDE.md     # 说明文档
```

### 关卡数据格式
```json
{
  "id": 1,
  "objective": "基础移动：让英雄到达宝箱",
  "learningContent": "基础移动指令、坐标概念",
  "availableCommands": ["moveRight()", "moveLeft()", "moveUp()", "moveDown()"],
  "codePlaceholder": "// 让英雄移动到宝箱位置\n// 使用 moveRight() 向右移动",
  "successMessage": "🎉 太棒了！你学会了基础移动！",
  "heroStart": { "x": 1, "y": 1 },
  "treasures": [{ "x": 3, "y": 3 }],
  "obstacles": [],
  "monsters": [{ "x": 5, "y": 5, "type": "physical" }],
  "weapons": [{ "x": 2, "y": 2, "type": "sword" }],
  "answer": "// 参考答案代码"
}
```

### 数据字段说明
- **id**: 关卡唯一标识符
- **objective**: 关卡目标描述
- **learningContent**: 学习内容说明
- **availableCommands**: 可用的编程指令列表
- **codePlaceholder**: 代码编辑器的初始提示代码
- **successMessage**: 通关成功消息
- **heroStart**: 英雄起始位置 `{x, y}`
- **treasures**: 宝箱位置数组 `[{x, y}, ...]`
- **obstacles**: 障碍物位置数组 `[{x, y}, ...]`
- **monsters**: 怪物配置数组 `[{x, y, type}, ...]`
- **weapons**: 武器配置数组 `[{x, y, type}, ...]`
- **answer**: 关卡参考答案代码

### 技术实现
```typescript

// 类型转换

```

### 优势
- **数据分离**：关卡数据与业务逻辑分离

- **版本控制**：JSON文件便于版本管理
- **批量操作**：可以批量处理关卡数据
- **国际化支持**：便于多语言版本管理

### 核心功能

#### 🛠️ 工具栏功能
1. **画笔工具**
   - 🦸 英雄：设置英雄起始位置（只能有一个）
   - 💰 宝箱：添加/删除宝箱
   - 🧱 障碍物：添加/删除障碍物
   - 👹 怪物：添加/删除怪物（可选择物理系/魔法系）
   - ⚔️ 武器：添加/删除武器（可选择剑/魔杖）
   - 🧽 橡皮擦：清除单元格内容

2. **关卡信息编辑**
   - 关卡ID、名称、学习内容
   - 成功消息、代码提示
   - 参考答案代码

3. **可用指令配置**
   - 多选框选择可用的编程指令
   - 支持所有游戏指令

#### 🗺️ 地图编辑区域
1. **可视化网格**
   - 可调整地图尺寸（5-20 × 5-15）
   - 点击放置/删除游戏元素
   - 实时显示坐标信息
   - 不同元素有不同的背景色

2. **交互操作**
   - 鼠标点击：放置/删除元素
   - 悬停效果：高亮显示单元格
   - 坐标显示：每个单元格显示坐标

#### 🎯 属性面板
1. **元素属性设置**
   - 怪物类型：物理系/魔法系
   - 武器类型：剑/魔杖

2. **统计信息**
   - 实时显示各类元素数量
   - 帮助检查关卡完整性

3. **JSON预览**
   - 实时生成关卡JSON数据
   - 便于复制和调试

### 操作流程

#### 创建新关卡
1. **点击"新建关卡"**
2. **设置关卡信息**
   - 填写关卡ID、目标、学习内容
   - 编写代码提示和参考答案
   - 选择可用指令

3. **设计地图**
   - 调整地图尺寸
   - 选择画笔工具
   - 在网格上点击放置元素

4. **配置元素属性**
   - 设置怪物类型（物理系/魔法系）
   - 设置武器类型（剑/魔杖）

5. **预览和测试**
   - 点击"预览关卡"测试游戏性
   - 调整关卡设计

6. **保存和导出**
   - 点击"保存关卡"下载JSON文件
   - 点击"导出JSON"复制到剪贴板

#### 编辑现有关卡
1. **点击"加载关卡"**
2. **粘贴JSON数据**
3. **在编辑器中修改**
4. **重新保存**
