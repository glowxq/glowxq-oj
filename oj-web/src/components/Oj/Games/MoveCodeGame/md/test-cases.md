# 🧪 CodeGame 测试用例

## 📋 测试目标

验证修复后的CodeGame组件能够正确处理：
1. for循环中的连续命令执行
2. 直接编写的连续命令执行
3. 嵌套循环和复杂逻辑
4. 动画速度控制

## 🔬 测试用例

### 测试用例 1：基础连续移动
**目标**：验证连续的移动命令能够按顺序执行，每个都有动画效果

```javascript
// 测试代码
moveRight()
moveRight()
moveRight()
moveDown()
moveDown()
moveLeft()
moveLeft()
moveLeft()
```

**预期结果**：
- 英雄应该依次执行8个移动动作
- 每个移动都应该有平滑的动画过渡
- 总共耗时约：8 × 300ms = 2.4秒（默认速度）

### 测试用例 2：简单for循环
**目标**：验证for循环中的命令能够正确重复执行

```javascript
// 测试代码
for(let i = 0; i < 3; i++) {
  moveRight()
}

for(let i = 0; i < 2; i++) {
  moveDown()
}

for(let i = 0; i < 3; i++) {
  moveLeft()
}
```

**预期结果**：
- 英雄先向右移动3步
- 然后向下移动2步  
- 最后向左移动3步
- 总共8个动作，每个都有动画

### 测试用例 3：嵌套循环
**目标**：验证复杂的嵌套循环逻辑

```javascript
// 测试代码
for(let i = 0; i < 2; i++) {
  for(let j = 0; j < 2; j++) {
    moveRight()
  }
  moveDown()
  for(let j = 0; j < 2; j++) {
    moveLeft()
  }
  if(i < 1) {
    moveDown()
  }
}
```

**预期结果**：
- 第1轮：右右下左左下
- 第2轮：右右下左左
- 总共11个动作

### 测试用例 4：动画速度控制
**目标**：验证动画速度可以动态调整

```javascript
// 测试代码
moveRight()
setAnimationSpeed(2)

for(let i = 0; i < 2; i++) {
  moveRight()
}

setAnimationSpeed(0.5)
moveDown()
moveDown()

setAnimationSpeed(1)
for(let i = 0; i < 3; i++) {
  moveLeft()
}
```

**预期结果**：
- 第1步：正常速度（300ms）
- 第2-3步：2倍速（150ms each）
- 第4-5步：0.5倍速（600ms each）
- 第6-8步：正常速度（300ms each）

### 测试用例 5：错误处理
**目标**：验证碰撞和边界检测

```javascript
// 测试代码（在关卡2中测试，有障碍物）
for(let i = 0; i < 10; i++) {
  moveRight()  // 应该在碰到障碍物时停止
}
```

**预期结果**：
- 英雄移动直到碰到障碍物
- 游戏状态变为失败
- 显示错误提示
