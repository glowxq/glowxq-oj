## 🔧 新增辅助函数

### hasObstacle(x, y)
**功能**：检查指定坐标是否有障碍物
**参数**：
- `x`: X坐标
- `y`: Y坐标
**返回值**：`boolean` - 有障碍物返回true，否则返回false

**使用示例**：
```javascript
if (hasObstacle(5, 3)) {
  moveUp() // 如果前方有障碍物，向上移动
} else {
  moveRight() // 如果前方没有障碍物，向右移动
}
```

### hasTreasure(x, y)
**功能**：检查指定坐标是否有未收集的宝箱
**参数**：
- `x`: X坐标
- `y`: Y坐标
**返回值**：`boolean` - 有宝箱返回true，否则返回false

**使用示例**：
```javascript
if (hasTreasure(10, 5)) {
  // 向宝箱位置移动
  moveRight()
  moveRight()
}
```

```typescript
  gameSettings.heroIcon = icon
  // 更新当前英雄的图标
  if (gameWorld.hero) {
    gameWorld.hero.symbol = icon
    renderGame()
  }

```

### 辅助函数实现
```typescript
const hasObstacle = (x: number, y: number): boolean => {
  return gameWorld.obstacles.some(obstacle => 
    obstacle.position.x === x && obstacle.position.y === y
  )
}

const hasTreasure = (x: number, y: number): boolean => {
  return gameWorld.treasures.some(treasure => 
    treasure.position.x === x && treasure.position.y === y && !treasure.collected
  )
}
```
