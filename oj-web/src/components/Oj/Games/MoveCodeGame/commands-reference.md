# 🎮 编程游戏指令参考手册

## 📋 指令分类概览

### 🎯 基础移动指令
最简单的移动控制，适合初学者

### 🚀 高级移动指令  
更高效的移动控制，支持方向和步数

### 📍 位置获取指令
获取游戏世界中各种元素的位置信息

### 🔍 位置检测指令
检查指定位置是否有特定元素

### 🧭 方向检测指令
检测指定方向是否有特定元素

### ⚔️ 战斗指令
战斗系统相关的指令

## 📖 详细指令说明

### 🎯 基础移动指令

#### `right()`
- **作用**: 向右移动一格
- **语法**: `right()`
- **示例**: `right() // 英雄向右移动一格`
- **级别**: 基础
- **返回值**: 无

#### `left()`
- **作用**: 向左移动一格
- **语法**: `left()`
- **示例**: `left() // 英雄向左移动一格`
- **级别**: 基础
- **返回值**: 无

#### `up()`
- **作用**: 向上移动一格
- **语法**: `up()`
- **示例**: `up() // 英雄向上移动一格`
- **级别**: 基础
- **返回值**: 无

#### `down()`
- **作用**: 向下移动一格
- **语法**: `down()`
- **示例**: `down() // 英雄向下移动一格`
- **级别**: 基础
- **返回值**: 无

---

### 🚀 高级移动指令

#### `dir(方向)`
- **作用**: 设置英雄面向方向
- **语法**: `dir(方向)`
- **参数**: 方向 (number) - 1=上, 2=右, 3=下, 4=左
- **示例**: `dir(2) // 朝向右方`
- **级别**: 中级
- **返回值**: 无

#### `go(步数)`
- **作用**: 向前移动指定步数
- **语法**: `go(步数)`
- **参数**: 步数 (number) - 要移动的格子数量，默认为1
- **示例**: `go(3) // 向前移动3格`
- **级别**: 中级
- **返回值**: 无

#### `turn()`
- **作用**: 向右转90度
- **语法**: `turn()`
- **示例**: `turn() // 向右转向`
- **级别**: 中级
- **返回值**: 无

---

### 📍 位置获取指令

#### `pos()`
- **作用**: 获取英雄当前位置
- **语法**: `pos()`
- **示例**: `const heroPos = pos()\nconsole.log("英雄在:", heroPos.x, heroPos.y)`
- **级别**: 中级
- **返回值**: {x: 横坐标, y: 纵坐标}

#### `treasurePos()`
- **作用**: 获取宝箱位置（只有一个宝箱时可用）
- **语法**: `treasurePos()`
- **示例**: `const treasure = treasurePos()\nconsole.log("宝箱在:", treasure.x, treasure.y)`
- **级别**: 中级
- **返回值**: {x: 横坐标, y: 纵坐标}
- **注意**: 地图上只有一个宝箱时才能使用，否则会报错

#### `weaponPos(类型)`
- **作用**: 获取武器位置
- **语法**: `weaponPos(类型)`
- **参数**: 类型 (number) - 1=剑, 2=魔杖
- **示例**: `const sword = weaponPos(1) // 获取剑的位置\nconst staff = weaponPos(2) // 获取魔杖的位置`
- **级别**: 中级
- **返回值**: {x: 横坐标, y: 纵坐标}
- **注意**: 地图上只能同时存在一个同类型武器，否则会报错

#### `weapon()`
- **作用**: 检测当前持有的武器类型
- **语法**: `weapon()`
- **示例**: `const myWeapon = weapon()\nif(myWeapon === 1) console.log("持有剑")`
- **级别**: 中级
- **返回值**: 1=剑, 2=魔杖, 0=无武器

---

### 🔍 位置检测指令

#### `hasObstacle(x, y)`
- **作用**: 检查指定位置是否有障碍物
- **语法**: `hasObstacle(x, y)`
- **参数**: 
  - x (number) - 横坐标
  - y (number) - 纵坐标
- **示例**: `if(hasObstacle(3, 4)) {\n  console.log("有障碍物")\n}`
- **级别**: 中级
- **返回值**: 有障碍物返回true，否则返回false

#### `hasTreasure(x, y)`
- **作用**: 检查指定位置是否有宝箱
- **语法**: `hasTreasure(x, y)`
- **参数**: 
  - x (number) - 横坐标
  - y (number) - 纵坐标
- **示例**: `if(hasTreasure(5, 6)) {\n  console.log("找到宝箱！")\n}`
- **级别**: 中级
- **返回值**: 有宝箱返回true，否则返回false

---

### 🧭 方向检测指令

#### `see(方向)`
- **作用**: 检测前方是否有障碍物
- **语法**: `see(方向)`
- **参数**: 方向 (number, 可选) - 1=上, 2=右, 3=下, 4=左，不传则检测前方
- **示例**: `if(see()) console.log("前方有障碍物")\nif(see(2)) console.log("右方有障碍物")`
- **级别**: 中级
- **返回值**: 有障碍物返回true

#### `seeTreasure(方向)`
- **作用**: 检测指定方向是否有宝箱
- **语法**: `seeTreasure(方向)`
- **参数**: 方向 (number, 可选) - 1=上, 2=右, 3=下, 4=左，不传则检测前方
- **示例**: `if(seeTreasure()) console.log("前方有宝箱")\nif(seeTreasure(1)) console.log("上方有宝箱")`
- **级别**: 中级
- **返回值**: 有宝箱返回true

#### `seeWeapon(方向)`
- **作用**: 检测指定方向是否有武器
- **语法**: `seeWeapon(方向)`
- **参数**: 方向 (number, 可选) - 1=上, 2=右, 3=下, 4=左，不传则检测前方
- **示例**: `if(seeWeapon()) console.log("前方有武器")\nif(seeWeapon(3)) console.log("下方有武器")`
- **级别**: 中级
- **返回值**: 有武器返回true

#### `seeMonster(方向)`
- **作用**: 检测指定方向是否有怪物
- **语法**: `seeMonster(方向)`
- **参数**: 方向 (number, 可选) - 1=上, 2=右, 3=下, 4=左，不传则检测前方
- **示例**: `if(seeMonster()) console.log("前方有怪物")\nif(seeMonster(4)) console.log("左方有怪物")`
- **级别**: 中级
- **返回值**: 有怪物返回true

---

### ⚔️ 战斗指令

#### `hit()`
- **作用**: 使用当前武器攻击前方怪物
- **语法**: `hit()`
- **示例**: `hit() // 攻击前方的怪物`
- **级别**: 中级
- **返回值**: 无
- **注意**: 需要先装备合适的武器：剑⚔️攻击物理系怪物👹，魔杖🪄攻击魔法系怪物🔮

## 🎯 使用技巧

### 💡 基础组合
```javascript
// 简单移动
right()
right()
down()

// 智能移动
dir(2)  // 朝右
go(3)   // 前进3步
```

### 💡 位置获取
```javascript
// 获取各种位置
const hero = pos()
const treasure = treasurePos()
const sword = weaponPos(1)

console.log("英雄位置:", hero.x, hero.y)
console.log("宝箱位置:", treasure.x, treasure.y)
console.log("剑的位置:", sword.x, sword.y)
```

### 💡 智能检测
```javascript
// 检测前方情况
if(see()) {
  console.log("前方有障碍物")
  turn()  // 转向
} else if(seeTreasure()) {
  console.log("前方有宝箱")
  go()    // 前进
} else if(seeMonster()) {
  console.log("前方有怪物")
  hit()   // 攻击
}
```

### 💡 武器系统
```javascript
// 检查武器状态
const myWeapon = weapon()
if(myWeapon === 0) {
  console.log("没有武器，需要寻找")
  // 寻找武器的逻辑...
} else {
  console.log("已装备武器，可以战斗")
}
```

这些指令让小朋友能够创建智能的游戏角色，从简单的移动到复杂的策略都能实现！
