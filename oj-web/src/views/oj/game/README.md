# 🎮 MoveCodeGame 测试平台使用指南

## 📋 功能概述

测试平台现在提供两种模式：

1. **🎮 游戏模式**：体验完整的编程学习游戏
2. **🗺️ 地图编辑器模式**：可视化创建和编辑关卡

## 🎯 访问方式

访问地址：`http://localhost:5174/oj/glowc/test`

## 🎮 游戏模式

### 功能特点
- **关卡选择**：10个精心设计的关卡，从基础到高级
- **实时编程**：在线代码编辑器，支持JavaScript语法
- **可视化反馈**：英雄移动动画，实时游戏状态
- **战斗系统**：武器与怪物的类型匹配机制
- **学习指导**：详细的游戏说明和编程提示
- **统计功能**：记录游戏进度和成就

### 关卡介绍
- **关卡1-3**：基础移动指令学习
- **关卡4-6**：循环和条件判断
- **关卡7-8**：复杂路径规划和算法思维
- **关卡9-10**：战斗系统和策略思维

### 使用步骤
1. 选择想要挑战的关卡
2. 阅读关卡目标和学习内容
3. 在代码编辑器中编写程序
4. 点击"运行代码"查看结果
5. 根据反馈调整代码直到通关

## 🗺️ 地图编辑器模式

### 功能特点
- **可视化编辑**：拖拽式地图设计
- **实时预览**：即时查看关卡效果
- **完整配置**：关卡信息、元素属性、指令设置
- **数据导出**：生成标准JSON格式关卡数据
- **关卡测试**：内置游戏引擎，直接测试关卡

### 使用步骤

#### 创建新关卡
1. **点击"新建关卡"**
2. **设置关卡信息**
   - 关卡ID和名称
   - 学习目标和内容
   - 成功消息和代码提示
   - 参考答案

3. **设计地图**
   - 调整地图尺寸（5-20 × 5-15）
   - 选择画笔工具
   - 在网格上点击放置元素

4. **配置元素**
   - 怪物类型：物理系👹/魔法系🔮
   - 武器类型：剑⚔️/魔杖🪄

5. **测试关卡**
   - 点击"预览关卡"
   - 在内置游戏中测试
   - 验证关卡可玩性

6. **保存导出**
   - 点击"保存关卡"下载JSON文件
   - 点击"导出JSON"复制数据

#### 编辑现有关卡
1. **点击"加载关卡"**
2. **粘贴关卡JSON数据**
3. **在编辑器中修改**
4. **重新保存**

### 工具说明

#### 🛠️ 画笔工具
- **🦸 英雄**：设置英雄起始位置（只能有一个）
- **💰 宝箱**：添加/删除宝箱（可多个）
- **🧱 障碍物**：添加/删除障碍物
- **👹 怪物**：添加/删除怪物
- **⚔️ 武器**：添加/删除武器
- **🧽 橡皮擦**：清除单元格内容

#### 🎯 属性设置
- **怪物类型**：
  - 物理系👹：需要剑⚔️攻击
  - 魔法系🔮：需要魔杖🪄攻击
- **武器类型**：
  - 剑⚔️：攻击物理系怪物
  - 魔杖🪄：攻击魔法系怪物

#### 📊 统计信息
实时显示地图中各类元素的数量：
- 英雄数量（应该为1）
- 宝箱数量
- 障碍物数量
- 怪物数量
- 武器数量

## 🎯 注意事项

### 关卡设计原则
1. **目标明确**：每个关卡应有清晰的学习目标
2. **难度递进**：关卡难度应逐步提升
3. **可完成性**：确保关卡有解决方案
4. **趣味性**：设计有趣的挑战和故事

### 常见问题
1. **英雄无法移动**：检查是否有障碍物阻挡
2. **武器无效**：确认武器类型与怪物类型匹配
3. **关卡无法完成**：检查是否所有宝箱都可到达
4. **JSON格式错误**：使用编辑器生成标准格式
